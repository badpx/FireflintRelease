FAQ

开始之前，
你可能想了解。

使用火石需要联网吗？

本地推理和 macOS OCR 在设备上运行。首次下载本地模型需要联网；当你使用联网检索、外部模型或第三方集成时，相应功能也需要网络连接。

使用火石需要支付 Token 费用吗？

本地模型在你的 Mac 上推理，不按 Token 计费。如果连接外部模型，相关使用费用由对应供应商决定。

可以使用自己的模型供应商吗？

可以。你可以使用内置本地模型，也可以连接外部模型服务。模型选择、隐私脱敏和工具授权分别可控。

可以读取哪些文档？

支持 PDF、Word、Excel 和 PowerPoint。扫描 PDF 可通过本地 OCR 辅助读取，文档中的图片也能按需查看。

如何安装火石？

从 GitHub Releases 下载 DMG，打开后将 Fireflint 拖入「应用程序」。启动应用后，按引导下载本地模型，并在需要时开启相应系统权限。
